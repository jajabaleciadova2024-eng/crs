Build Order — Workstation & Leave Management App

Living checklist of what's built and what's left.

Stack: Next.js (App Router) + Supabase (Postgres, Auth, RLS) + Tailwind v4 · Roles: team_leader (highest) > oic > associate — Team Leader and OIC are collectively "leadership"/"approvers" (isApprover() in src/lib/auth.ts).

✅ Done

  • DONESchema & RLS (supabase/migrations/0001_init.sql) — profiles, workstations, schedule_weeks, assignments, leave_requests, org_settings, notification_prefs, all with row-level security policies scoped by role/ownership.
  • DONEAuth (src/lib/supabase/*, src/lib/auth.ts, src/app/login) — Supabase SSR client/middleware, session guard + role helpers, login page supporting sign-in by PSID or email.
  • DONEApp shell (src/components/*) — sidebar nav, sign-out, shared UI primitives, protected (app) layout.
  • DONEDashboard (src/app/(app)/page.tsx)
  • DONETeam management (src/app/(app)/team/*, src/app/api/team/route.ts) — list/add members, role edit, /api/team route using the service-role client to invite users via Supabase Auth.
  • DONEWorkstations CRUD (src/app/(app)/workstations/*)
  • DONELeave requests (src/app/(app)/leave/*) — submit form, approve/reject actions, RLS prevents self-approval.
  • DONESettings (src/app/(app)/settings/*) — account form, org settings (cadence, leave types, required reason, approver roles), notification-preference toggles.
  • DONESchedule page (read/manual) (src/app/(app)/schedule/*) — shows current week's assignments, manual reassignment form for leadership.
  • DONESeed script (scripts/seed.mjs) — provisions initial workstations + first Team Leader account via invite email.
